# UnrealORM Documentation Revamp Plan

This is a plan to make the docs accurate, complete, and useful for three audiences: people who do not know SurrealDB, people who know SurrealDB but are new to the ORM, and advanced users.

## 1. Goal and scope

- **Correct first**: every code block must compile against the current `unreal-orm` and `@unreal-orm/cli` APIs.
- **Cover the full public API**: all exports from `packages/unreal-orm/src/index.ts` and `packages/unreal-cli/src/index.ts` must have a dedicated doc page or section.
- **Teach SurrealDB through UnrealORM**: where the library wraps a SurrealDB concept, explain both.
- **Explicitly document the boundary**: features the ORM does not support (events, triggers, custom functions, scopes/tokens, vector indexes, time-series) should point users to raw `surrealdb` SDK usage.

## 2. Target audiences

| Audience | What they need | Where they live in the docs |
|---|---|---|
| **SurrealDB beginners** | What is SurrealDB, how to run it, record IDs, `SCHEMAFULL`, `SCHEMALESS`, `surql` templates, graph edges | New "SurrealDB in 5 minutes" primer + tutorial |
| **SurrealDB users new to UnrealORM** | Mapping table → `Table.normal`, link → `Field.record`, index → `Index.define`, query → `surql` vs field-proxy | New "Concepts" and "SurrealQL → UnrealORM" reference |
| **Advanced users** | Type-safe selects, `typed()`, `where` builders, migrations, AST, testing, permissions | Deep-dive guides + API reference |

## 3. Proposed information architecture

Reorganize `apps/docs/src/content/docs/` into a deliberate learning path. Each top-level item becomes a sidebar group.

```
docs/
├── index.mdx                         # Landing page (rewrite for clarity)
├── getting-started/
│   ├── what-is-surrealdb.mdx         # NEW: prerequisite concepts
│   ├── installation.mdx              # NEW: install SurrealDB + ORM + CLI
│   ├── quickstart.mdx                # NEW: minimal end-to-end example
│   └── capabilities.md               # Rewrite: split into quick matrix + detailed pages
├── concepts/
│   ├── models-and-tables.mdx         # Table.normal / relation / view
│   ├── fields-and-types.mdx          # Field.* builders
│   ├── indexes.mdx                   # Index.define options

│   ├── deleting.mdx                  # delete, deleteMany
│   └── relations.mdx                 # relate, graph traversal, fetch
├── advanced/
│   ├── permissions.mdx               # Move/expand security-permissions.mdx
│   ├── full-text-search.mdx          # Index.search + analyzer
│   ├── geospatial.mdx                # Field.geometry
│   ├── file-storage.mdx              # Bucket.define + Field.file
```

### Why this ordering

The current `guides/` directory is autogenerated alphabetically. A new user sees "AI Usage" before "Tutorial". The proposed order moves from prerequisites → concepts → queries → advanced topics.

## 5. Accuracy verification plan

Before writing any new page, verify against these sources:

1. **Code is the source of truth**
   - `packages/unreal-orm/src/index.ts` for all public exports.
   - `packages/unreal-orm/src/define/field/index.ts` for `Field.*` builders.
   - `packages/unreal-orm/src/define/table/index.ts` for `Table` factories and CRUD methods.
   - `packages/unreal-orm/src/define/table/types/query.ts` for `select`, `update`, `insert`, `count` options.
   - `packages/unreal-orm/src/define/table/types/select.ts` for `typed()` and projection types.
   - `packages/unreal-orm/src/query/field-proxy.ts` for query builder operators.
   - `packages/unreal-orm/src/unreal.ts` for the `Unreal` namespace.
   - `packages/unreal-orm/src/define/bucket/index.ts` for `Bucket`.
   - `packages/unreal-cli/src/index.ts` and `packages/unreal-cli/src/commands/*.ts` for CLI commands.
   - `packages/unreal-cli/src/utils/config.ts` and `connect.ts` for config and connection resolution.

2. **SurrealDB reference**
   - `surrealdb-docs/src/content/learn/` for conceptual coverage.
   - `surrealdb-docs/src/content/reference/query-language/` for SurrealQL statement syntax.
   - `surrealdb-sdk/packages/sdk/README.md` for SDK connection and `surql` usage.

3. **Automated checks**
   - Extract every TypeScript code block from `apps/docs/src/content/docs/**/*.mdx` into a temporary `docs-examples/` package.
   - Add `tsconfig.json` that depends on `unreal-orm` and `surrealdb`.
   - Run `tsc --noEmit` as part of CI.
   - Add `astro check` and a broken-link checker to the docs build.

4. **Generated content**
   - Commit generated `api/` and `cli/` pages, or generate them in CI before deploy.
   - The `apps/docs/scripts/generate-cli-docs.ts` script should use `@unreal-orm/cli` source, not `unreal-orm`.

## 7. Definition of done

- The sidebar follows the proposed learning path.
- Every public export in `packages/unreal-orm/src/index.ts` and `packages/unreal-cli/src/index.ts` is documented.
